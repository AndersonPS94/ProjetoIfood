## 🛠️ Tecnologias Utilizadas  
Este projeto foi desenvolvido com as seguintes tecnologias:  

✅ Kotlin

✅ Arquitetura MVVM

✅ Gradle Kotlin DSL

✅ Injeção de dependências com hilt

✅ Coroutines para operações assíncronas

✅ Navigation Component para navegação entre telas

✅ ViewModel e LiveData para gerenciamento de estado

✅ Data Binding para vinculação de dados à UI

✅ Firebase

 - Authentication: Para gerenciamento de usuários.​

 - Realtime Database: Para armazenamento e sincronização de dados em tempo real.​

 - Cloud Storage: Para armazenamento de imagens e outros arquivos.

## 📂 Estrutura do Projeto
O projeto é modularizado em três principais módulos:

```plaintext
📂 ProjetoIfood
├── 📂 cliente         # Módulo responsável pela interface do cliente
├── 📂 loja            # Módulo responsável pela interface da loja
├── 📂 core            # Módulo compartilhado com recursos comuns
├── build.gradle.kts   # Configurações do projeto
├── settings.gradle.kts
```


## 📄 Aprendizados
Durante o desenvolvimento deste projeto, foram explorados os seguintes conceitos:

✅ Modularização de projetos Android

✅ Implementação do padrão MVVM

✅ Utilização do Hilt para injeção de dependências

✅ Gerenciamento de navegação com Navigation Component

✅ Manipulação de dados assíncronos com Coroutines

✅ Integração de módulos compartilhados com o módulo core

## 🚀 Como Executar  

Para rodar o projeto na sua máquina, siga estes passos:  

```bash
# Clone este repositório
git clone https://github.com/AndersonPS94/ProjetoIfood.git

# Acesse a pasta do projeto no terminal
cd ProjetoIfood

# Abra o projeto no Android Studio e execute no emulador ou dispositivo real.
```
